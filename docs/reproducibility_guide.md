# Reproducibility Guide

**Audience:** anyone who wants to run this project from scratch — a grader, a
teammate, or a future student.

**Goal:** from a fresh clone to a working Streamlit dashboard, with all 252
tests passing, in roughly 3–5 minutes.

This guide was verified end-to-end on 2026-11-14 against commit `a31687a`
on branch `feature/phase-4`.

---

## 1. Prerequisites

- **Git**
- **Python 3.14** (other versions 3.10+ will work; only 3.14 was tested)
- **pip** (bundled with Python)
- Internet access for the initial `yfinance` download (~15 seconds once)

**Disk space:** ~200 MB (mostly the `.venv` with numpy/scipy/pandas).

---

## 2. Clone the Repository

```bash
git clone https://github.com/asj-cs-cjc-rvu-binary-1000/05-Financial-Portfolio-Optimization-and-Risk-Allocator.git
cd 05-Financial-Portfolio-Optimization-and-Risk-Allocator
git checkout feature/phase-4
```

**Expected:** branch `feature/phase-4` checked out.

---

## 3. Create and Activate a Virtual Environment

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows (PowerShell)
# .venv\Scripts\Activate.ps1
```

**Expected:** shell prompt now prefixed with `(.venv)`.

**Verify:**

```bash
which python           # Linux/macOS → .../05-.../.venv/bin/python
python --version       # Python 3.14.x
```

## 6. Run the Test Suite

```bash
pytest tests/ -v
```

**Expected:** `252 passed in ~5s`.

If any test fails, check:
- `.venv` is activated
- `pytest.ini` exists at repo root (it does — do not delete it)
- `data/` is not empty (if test loads a CSV; most tests use synthetic data and do not need it)

---

## 7. Run the CLI Pipelines

```bash
# Data → returns → covariance (Phase 2 + 3)
python -m src.preprocessing.returns

# Optimize portfolios (Phase 4)
python -m src.optimization.optimization_pipeline

# Compute risk metrics (Phase 5)
python -m src.risk.comparison
```

Each command prints a table and writes a live report to `docs/`:
- `docs/return_summary.md`
- `docs/optimization_summary.md`
- `docs/risk_analysis.md`

## 8. Launch the Dashboard

```bash
streamlit run app/app.py
```

**Expected:**
```
You can now view your Streamlit app in your browser.
  Local URL: http://localhost:8501
  Network URL: http://<your-ip>:8501
```

Open `http://localhost:8501` in a browser.

**Verify:**
- Title `Financial Portfolio Optimizer` renders
- Sidebar shows 6 controls
- Three tabs: Optimization, Risk Analysis, Frontier
- Optimization tab shows the 3-strategy comparison table
- Risk Analysis tab shows VaR/CVaR/MDD + drawdown chart + VaR histogram
- Frontier tab shows the six-layer efficient frontier

**If the port is busy**, run with `streamlit run app/app.py --server.port 8502`
or higher.

**To stop:** Ctrl+C in the terminal.

## 11. Troubleshooting

| Symptom | Fix |
|---|---|
| `ModuleNotFoundError: No module named 'src'` | Activate `.venv`; ensure you run commands from the repo root (not `app/`) |
| `FileNotFoundError: data/processed/prices_clean_*.csv` | Run `python -m src.data.stock_data` |
| Streamlit opens but shows a blank page | Check the Streamlit terminal for traceback; refresh the browser |
| `kaleido` deprecation warning | Expected — see `docs/environment_versions.md` |
| `pytest` finds 0 tests | Ensure `pytest.ini` exists at repo root |
| Streamlit port 8501 busy | `streamlit run app/app.py --server.port 8502` |

---

## 12. What "Reproducibility" Means Here

- **Deterministic tests.** All 252 unit tests use synthetic fixtures or deterministic seeds. No network, no randomness, no flakiness.
- **Deterministic CLI.** `compare_portfolios`, `compare_risk_metrics`, and `analyze_frontier` produce byte-identical output on the same machine and library versions. Cross-machine SLSQP drift is bounded at 1e-8 (documented in `docs/mathematical_foundations.md` §11.9).
- **Pinned dependencies.** `requirements.txt` uses exact `==` pins. `docs/environment_versions.md` documents every pin and its rationale.
- **No committed data.** All CSVs are generated; the `.gitkeep` files only preserve the folder structure.
